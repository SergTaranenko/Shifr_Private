# Портфельный советник — Telegram-бот

Бот следит за котировками и новостями по вашим бумагам, сигналит о важном и **присылает прогноз из модели**.
Модель справедливой стоимости он не меняет: её вы обновляете вместе с Claude и кладёте в GitHub.

## Как это устроено

```
GitHub (приватный репозиторий)  →  BotHost (берёт код при каждом push)  →  бот в Telegram
  код бота + model/model.xlsx        TELEGRAM_TOKEN и GIGACHAT_CREDENTIALS      читает модель из model/model.xlsx
                                     хранятся только здесь                       и присылает вам прогноз
```

**Главное правило:** токен бота и ключ GigaChat **никогда не кладите в репозиторий** — только в переменные окружения в панели BotHost.
Репозиторий делайте **приватным**: в книге модели есть ваши позиции.

Бумаги в модели: SBER, PLZL, POSI, PRMD, YDEX, MTSS, GAZP, NLMK и **BSPB (Банк Санкт-Петербург) — для справки**: модель и новости по нему есть, позиции в портфеле нет.

## Прогноз

- после каждого обновления модели в GitHub бот сам присылает **«📘 Действующий прогноз»**: что изменилось в справедливых ценах и допущениях, таблицу по всем бумагам и саму Excel-книгу;
- **раз в неделю** (по понедельникам в 09:30 МСК) — полный прогноз и копия книги;
- `/forecast` — прогноз по всем бумагам: справедливая цена, из чего она складывается (база + ИИ + мир, у Газпрома — опционы), границы покупки и продажи, главные допущения, тезис и условия слома;
- `/forecast SBER` — то же по одной бумаге;
- `/model` — прислать Excel-книгу действующей модели.

## Что бот присылает сам

| Когда | Что |
|---|---|
| 10:05, 14:05, 18:05, 22:05 МСК | только если бумага сменила зону: покупка / держать / близко к продаже / продажа |
| там же | если цена за день изменилась больше чем на 5% (раз в день на бумагу) |
| каждый час | новости, которые могут изменить модель (🟠) или похожи на слом тезиса (🔴), с готовой фразой «Обсудить с Claude» |
| 19:00 | если курс доллара или золото ушли от допущений модели больше чем на 10% (не чаще раза в неделю) |
| 20:30 | итоги дня: цены против справедливых, курс и золото, новости за сутки |
| понедельник 09:30 | прогноз целиком и копия книги |
| после обновления модели | новый прогноз с изменениями и книга |

Зоны берутся из модели: покупка — цена не выше справедливой −23%, продажа — от справедливой +18%, «близко к продаже» — за 5% до неё.
Смена зоны засчитывается, только когда цена ушла за границу дальше чем на 0,5% — так бот не дёргается на границе.

Новости — из лент РБК, Интерфакса, Коммерсанта, ТАСС, Ведомостей, Прайма и из Google News по каждой компании.
GigaChat читает каждую подходящую новость вместе с тезисом и условиями слома из модели и ставит уровень:
полезно знать (в итоги дня), может изменить модель (сразу), похоже на слом тезиса (сразу).
Если GigaChat не отвечает, бот оценивает новости по ключевым словам.

## Остальные команды

`/status` — цены против справедливых и стоимость портфеля · `/levels` — уровни покупки и продажи ·
`/news` — новости за сутки · `/digest` — итоги дня сейчас · `/check` — проверить котировки сейчас ·
`/checknews` — проверить новости сейчас · `/macro` — курс и золото против модели · `/health` — что работает, а что нет

## Запуск

1. **Репозиторий.** Загрузите содержимое этой папки в приватный репозиторий (у вас — `SergTaranenko/Shifr_Private`, ветка `main`):
   на сайте GitHub Add file → Upload files → перетащить файлы и папки → Commit changes.
   `main.py` должен лежать в той папке, из которой BotHost запускает бота (обычно — корень репозитория).
   Файлов `.env` и токенов в репозитории быть не должно.
2. **BotHost.** Подключите репозиторий в панели BotHost. Файл запуска — `main.py`, зависимости — `requirements.txt`,
   Python 3.11 или новее. Если панель предлагает Docker — в папке есть `Dockerfile`.
3. **Переменные окружения в панели BotHost:**
   - `TELEGRAM_TOKEN` — токен от @BotFather (обязательно)
   - `GIGACHAT_CREDENTIALS` — ключ авторизации GigaChat
   - `DATA_DIR` — путь к постоянному диску (Volume) вашего тарифа. Тогда бот помнит, какие сигналы и прогнозы уже присылал, и не повторяет их после перезапуска.
     Без него бот хранит это в папке `state/` и после каждого обновления из GitHub начинает с чистого листа
   - `OWNER_CHAT_ID` — ваш chat id (бот покажет его после `/start`)
4. **Первый запуск.** Напишите боту `/start` — он запомнит вас как владельца, покажет chat id и сразу пришлёт действующий прогноз.
   Затем `/health` — бот проверит биржу, курс, золото, ленты новостей и GigaChat.

Первая проверка новостей после запуска проходит молча: бот запоминает уже вышедшие новости и сигналит только о новых.

## Где бот ищет модель

По очереди: **`model/model.xlsx`** → `data/model.xlsx` → `model.xlsx` в корне репозитория → запасная копия `advisor/data/model.xlsx`.
Команда `/health` показывает, из какой папки модель взята на сервере («Папка модели на сервере») — там должно быть `…/model`.

Папку `data/` BotHost, судя по всему, закрывает постоянным диском, поэтому модель лежит в отдельной папке `model/`.
Свои данные (что уже присылал) бот сам хранит на этом постоянном диске.

## Как обновлять модель

1. Обсуждаете изменения с Claude — он присылает новую книгу.
2. В репозитории на GitHub откройте папку `model`, нажмите Add file → Upload files и загрузите книгу под именем
   **`model.xlsx`** (если файл называется «Модели_справедливой_стоимости.xlsx» — сначала переименуйте).
3. BotHost подтянет изменения и перезапустит бота, а бот пришлёт «📘 Действующий прогноз» с изменениями и книгой.

Можно и просто прислать книгу боту в чат — она начнёт действовать сразу. Но главная версия — та, что в GitHub:
как только там появится новая книга, бот переключится на неё. Поэтому присланную в чат книгу тоже кладите в репозиторий.

`advisor/data/levels.json` — запасная копия цифр: бот берёт её, только если книгу в репозитории прочитать не удалось.

## Если бот не запускается или молчит

1. Откройте в BotHost «Логи работы».
2. `FileNotFoundError … /app/data/…` — старая версия бота искала файлы в `data/`, а на сервере эта папка закрыта постоянным диском.
   Загрузите в репозиторий папки `advisor/` и `model/` из этой версии: она ищет модель в `model/`, а ленты и названия компаний
   встроены в код.
3. `Не задан TELEGRAM_TOKEN` — переменная не задана в панели BotHost.
4. Бот запустился, но GigaChat или курс ЦБ в `/health` с ошибкой — сервер BotHost может стоять за границей (например, в Нидерландах),
   а эти сервисы иногда не отвечают на зарубежные адреса. Если BotHost позволяет выбрать сервер в России — выберите его.
   Без GigaChat бот оценивает новости по ключевым словам, без ЦБ — берёт курс с запасного источника.

## Настройки

Все параметры с пояснениями — в `.env.example`: время проверок, день и время еженедельного прогноза, пороги сигналов,
модель GigaChat (по умолчанию `GigaChat-2`), сколько новостей за раз отдавать GigaChat (по умолчанию 30).
Ленты новостей и названия компаний для поиска в новостях встроены в код (`advisor/defaults.py`).
Чтобы поменять их без правки кода, положите `feeds.json` или `aliases.json` в папку `model/` — бот возьмёт их вместо встроенных.

**Сертификат GigaChat.** API GigaChat использует сертификаты НУЦ Минцифры, которых нет в обычных серверных системах.
По умолчанию проверка сертификата выключена (`GIGACHAT_VERIFY_SSL=false`), чтобы всё заработало сразу.
Безопаснее положить корневой сертификат Минцифры (gosuslugi.ru/crt) в репозиторий,
указать путь в `GIGACHAT_CA_BUNDLE` и поставить `GIGACHAT_VERIFY_SSL=true`.

## Что важно знать

- Котировки Мосбиржи бесплатные и идут с задержкой около 15 минут — для долгосрочного инвестора этого достаточно.
- Бот не торгует и не даёт советов купить или продать: он сообщает, что произошло, и присылает прогноз модели. Решения — ваши.
